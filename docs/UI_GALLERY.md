# Gallery UI

Gallery chỉ là file local `artifacts/ui-hubs/gallery.html` để xem và duyệt UI trong chat. Không có route gallery trong ứng dụng game hoặc bản deploy. File HTML tự chứa ảnh và các mẫu component tương tác với dữ liệu giả; không gọi API phòng hoặc database. Các ảnh có thể bấm để xem lớn.

Các UI đã duyệt vẫn được sử dụng trong game. Gallery gồm 25 bảng thao tác và 20 công trình đặc trưng. Nút giao dịch trên bàn cờ và ba mẫu tạo/nhận/chờ giao dịch trong gallery được ẩn vì không sử dụng; giao thức giao dịch giữ nguyên.

Nguồn minh họa và hash nằm trong `docs/art/landmarks-cartoon-v1.json`; asset sử dụng trong game nằm tại `public/assets/landmarks/cartoon-v1`.
